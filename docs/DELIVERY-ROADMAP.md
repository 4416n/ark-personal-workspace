# 交付可靠性实施计划

按依赖分阶段交付；勾选表示代码和回归验证已完成，不代表只有界面或方案。

## 产品范围

BOSS 方舟定位为面向一人公司的 OPC 个人工作台：一位使用者管理自己的项目、AI 员工、知识与交付物，电脑和手机访问同一份工作台。发布与验收围绕个人自部署、安装维护、数据可靠性和实际交付展开，不以多人账号、多租户 SaaS 或平台计费为建设目标。

个人使用仍需明确模型费用、保护本机数据与密钥，并隔离运行生成的代码。手机当前限可信局域网；外出访问另行设计，不因个人定位而直接开放公网。

产品概览见 [项目首页](../README.md)，操作说明见 [使用手册](USER-GUIDE.md)，已发布变更见 [更新记录](CHANGELOG.md)。

## 用户确认的实施约束
- 不新增按项目或员工累计的 Token 上限、Token 预算熔断功能。保留用量记录；现有单次请求输出参数、超时、人工停止和有限重试不是新增的累计 Token 配额，不因此改成无限执行。
- 当前模型配置为全局一组 Base URL、模型名和 API Key：规划、AI 员工交付、AI 审查及工程生成共用，角色通过提示词和任务上下文区分。本次不擅自改为每个员工单独配置密钥。

## 复查新增整改（先于第二阶段）
- [x] 持久化验收反例：临时测试网站只返回固定样例、创建空 SQLite 而不保存业务记录，仍能通过现有检查。增加运行时生成的测试数据、跨重启读回与修改/删除验证，不能仅依据模型自己提供的固定断言判断业务完成。
- [x] 稳定基线反例：过期旧源码重验后会成为最近成功记录，后续失败可能挤掉较新的成功源码。区分源码版本与重验记录，修正自动保留和推荐续写起点，并增加回归测试。

本轮实现（3.3.1）：动态契约的随机数据由验证器生成，检查声明业务字段的真实 SQLite 数据，跨重启读回，浏览器另用随机值并在无缓存上下文读回。修改/硬删除未声明时明确未覆盖；旧工程缺少契约不冒充新验收通过。源码来源/代次随重验和完整备份保留，推荐和保护统一使用源码基线。工程面板按需加载，保持现有布局。

验证：生产构建、85 项逻辑/API、45 项页面、7 项真实工程页面、10 项真实隔离测试通过；新反例覆盖固定样例、内存假持久化、忽略更新/删除、只依赖浏览器缓存、旧版重验挤掉基线。真实工程页面与隔离套件应串行运行，后者会检查验证服务是否已全部退出，不能与其他真实沙箱作业并行。测试使用临时数据和模拟模型。上述检查仍不是所有业务需求的完整验收。

## 第一阶段：保护已有成果（优先）
- [x] 稳定工程保留：最近成功版与手动锁定版不会被失败记录挤掉；运行中不清理；限额、解除锁定与淘汰规则明确。
- [x] 精准需求指纹：只比较影响实现的语义输入；颜色、排序、状态、复盘不触发过期；旧版本不擅自套用新指纹。
- [x] 完整迁移备份：包含业务、工程、日志、批次与快照；格式版本/校验和/容量限制；本机预览确认恢复；恢复前独立备份；不导出/覆盖模型凭据，不恢复自动花费或已有设备授权。

验收：历史成功版+连续失败仍可下载，元数据编辑不误判而真实需求变更仍过期，换空目录恢复全部数据、损坏备份拒绝且无部分写入，手机不能恢复整机。

本地验证（3.3.0）：生产构建成功；78 项逻辑/API、44 项页面、6 项真实工程页面和 4 项真实隔离测试全部通过。页面覆盖桌面与 390px；测试使用临时数据和模拟模型，不调用用户的模型密钥。真实隔离测试仅代表当前 Linux 环境通过，不等同所有平台或任意业务项目均已验收。

## 第二阶段：交付过程可恢复、可验收
- [x] 分阶段工程执行：需求与接口契约、前后端实现、集成、测试；阶段产物和费用留痕，仅重做失败阶段。
- [x] 检查点：重启/网络中断保留有效阶段及草稿；恢复前确认剩余执行范围与重试次数，不自动重做已完成阶段，不增加累计 Token 配额。
- [x] 逐条验收：需求映射到文件和测试证据；明确未覆盖/失败/待人工，不将构建通过等同全部需求完成。

验收：中途停止、重启后经确认从正确阶段恢复，不重复执行已完成阶段；缺少任何需求证据时不能宣称整体验收通过。

3.4.0：固定粗粒度阶段、检查点恢复与逐条验收记录已实现。每项原始要求保留，AI 引用经存在性检查，但语义覆盖由人工确认；不是所有需求都有自动测试。完整备份保留草稿，恢复清除当前验证与审批。阶段内截断响应不承诺增量恢复，任意工具循环/自动部署不在本轮。详见 [分阶段交付](STAGED-DELIVERY.md)。

## 第三阶段：真正可试用的交付
- [ ] 安全交互预览：操作系统隔离、独立源或受控远程浏览器；不信任生成页面，不与工作台同源；过期回收/可停止/手机操作。
- [ ] 部署中心：运行指引、环境检查、容器构建证据、部署日志；公开部署/绑定域名/密钥输入须另行确认。

验收：实际填表、写库与刷新读回；预览不能访问宿主文件、密钥、网络/工作台 API；无可靠隔离时禁用而非退回宿主执行。

## 第四阶段：知识、手机与复用
- [ ] 项目知识升级：文件导入、增量索引、来源与过期标记；可选向量混合检索并明确费用，关键词模式可独立工作。
- [ ] 手机待办与提醒：完成/失败/审批中心、离线草稿；不自动推送敏感正文。真正外出访问的 VPN/安全隧道另行配置，不裸露公网。
- [ ] 工程流程模板：版本化的工程骨架、验收用例及执行配置，实例化时清除业务数据/凭据/旧验收结论。
