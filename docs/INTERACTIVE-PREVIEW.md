# 隔离交互预览（3.5 待发布）

工程交付面板提供“安全交互预览”入口。它将浏览器放在 Linux 操作系统隔离环境中，工作台只接收 PNG 图像，通过有限动作请求控制隔离浏览器；生成网页的 HTML 和脚本不进入工作台的页面源。

## 使用条件与范围

- 仅支持满足现有 Linux / Node.js 24 / bubblewrap / systemd 用户服务 / Chromium 条件的环境；嵌套 user / PID 命名空间也必须可用。Windows/macOS 不退回主机执行。
- 只允许状态为 verified、验证器版本匹配、实际检查通过，且验证源码指纹与当前源码一致的完整工程。恢复的旧记录和无对应源码指纹的历史报告必须先重验；需求过期需要重新生成并验证。
- 全工作台最多一个会话。启动、工程生成/重验与整机恢复互斥；预览期间不得修改该项目需求。会话绑定启动它的本机或配对设备授权。
- 会话最多 10 分钟，90 秒无用户操作会结束；读取图像不续期。临时 SQLite 数据随会话停止清理，不能作为实际业务数据保存服务。
- 支持点击、输入文字、有限按键、滚动、刷新、桌面/手机视口、重启应用。接口不接受自定义 URL、文件路径、shell 或任意 JavaScript。
- 工作台只接收限定尺寸与长度的 PNG。隔离外层运行可信控制器及 Chromium；应用后端在第二层独立 user / PID / proc / tmp 环境运行，仅共享私有 loopback 和临时业务数据，避免接触控制器输出通道。
- 停止时清理 systemd 管理的整个进程树；无法确认停止时保持执行锁，界面保留重试停止入口。不得把清理请求已发出等同清理完成。

界面出现图像不代表所有业务要求已经验收，预览不会自动修改人工审批结果。平台没有提供公开网站托管、域名或生产密钥输入；实际部署仍需独立准备。

## 验证与发布要求

本轮在 Windows 对协议、授权、过期、源码绑定、输入/图像边界、停止失败和迟到响应进行了模拟测试，浏览器覆盖桌面、390px 和停止重试。模拟测试不证明 Linux 命名空间实际可用，也不替代独立安全审计。

受支持 Linux 上需顺序运行：

```sh
npm ci
npm run build
npx playwright install --with-deps chromium
npm run test:sandbox
ARK_REAL_BROWSER_BUILD=1 npx playwright test tests/browser/software.spec.ts --workers=1
npm run test:preview
```

新增真实预览套件检查实际点击/输入、SQLite 重启后无缓存读回、宿主文件/网络不可访问、平台脚本只读、应用无法通过父进程文件描述符冒充截图，以及取消后的进程树清理。套件必须串行，不能与其他真实隔离测试同时运行。当前工作环境尚未执行这组 Linux 实测，发布前必须取得实际通过记录。
